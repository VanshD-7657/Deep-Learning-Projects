# 📂 Projects Included

## 🩺 1. Breast Cancer Detection

Goal: Classify tumors as benign or malignant using diagnostic features.

Dataset: Breast Cancer Wisconsin Dataset (Scikit-learn).

#### Highlights:

Applied TensorFlow/Keras dense network.

Achieved strong accuracy and reliable predictions.

Focus on early detection for healthcare applications.

## 2. Fake News Detection with LSTM

Goal: Detect whether a news article is real or fake using Natural Language Processing (NLP) and a deep learning model.

Dataset: Custom news dataset with columns: title, text, label (0=Real, 1=Fake).

#### Highlights:

Applied preprocessing steps: text cleaning, stopword removal, tokenization, stemming, and padding.

Built an LSTM-based neural network with an Embedding layer, BatchNormalization, dropout, and L2 regularization.

Integrated EarlyStopping to prevent overfitting.

Achieved high classification accuracy in distinguishing real vs fake news.
  
## 🔢 3. MNIST Handwritten Digit Classification

Goal: Predict handwritten digits (0–9) using a CNN.

Dataset: MNIST (60,000 training, 10,000 testing).

#### Highlights:

Built a CNN with high accuracy (~97%).

Supports predictions on custom handwritten images.
